# 桌面歌词实现计划

## 目标

- Electron 桌面端原生提供桌面歌词，不依赖外部 `osdlyrics`。
- Windows、Linux、macOS 使用同一套开关和歌词同步协议。
- 关闭功能时不创建窗口、不发送无效渲染状态。

## 设计

1. 主进程管理透明、无边框、置顶、跳过任务栏的歌词窗口。
2. 现有歌词解析器继续作为唯一歌词数据源。
3. Renderer 在当前歌词行变化时通过受限 IPC 发送原文和翻译。
4. Preload 分离“主窗口发送”和“歌词窗口接收”能力，保持 `contextIsolation`。
5. 设置项使用 `enableDesktopLyrics`；旧 `enableOsdlyricsSupport` 自动迁移。

## 实施步骤

1. 新增桌面歌词窗口控制器及生命周期测试。
2. 扩展 preload 与主进程 IPC。
3. 调整歌词轮询，使主歌词页隐藏时仍可更新桌面歌词。
4. 将 Linux-only OSDLyrics 设置替换为全平台内置开关。
5. 移除外部进程启动逻辑，补充配置迁移和多语言文案。

## 验收标准

- 开启后显示当前歌词；有翻译时显示第二行。
- 主歌词页关闭时，桌面歌词仍持续更新。
- 切歌、无歌词和关闭功能时，旧歌词不会残留。
- 窗口不抢焦点、不出现在任务栏、保持置顶并忽略鼠标事件。
- 完整测试、ESLint、Web 与 Electron 构建通过。
