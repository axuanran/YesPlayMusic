# 播客功能实现计划

## 目标

- 提供播客发现、节目详情和单集播放的最小可用闭环。
- 复用现有播放器、播放队列和封面组件，不建立第二套音频内核。
- Windows、Linux、macOS 与 Web 使用同一套页面和数据模型。

## 设计

1. 新增播客 API 层，封装推荐节目、节目详情和单集列表接口。
2. 新增 `/podcast/:id?` 页面；无 `id` 时展示推荐节目，有 `id` 时展示节目资料与单集。
3. 将单集的 `mainSong` 规范化为现有 Track 数据结构，再交给播放器队列。
4. 导航栏增加播客入口，并补齐四种现有语言的界面文案。
5. 对单集规范化、无效数据过滤和播放顺序增加单元测试。

## 实施步骤

1. 实现播客 API 与纯数据转换函数。
2. 实现推荐节目卡片和节目详情/单集列表。
3. 接入路由、导航、多语言与加载/错误状态。
4. 验证单集播放、切换节目、空列表和 API 异常场景。

## 验收标准

- 导航栏可进入播客页，并显示推荐节目。
- 点击节目可查看封面、作者、简介和单集列表。
- 点击单集或“播放全部”可使用现有底部播放器播放，并按列表顺序切换。
- 接口失败时显示可重试状态，不遗留加载动画。
- 完整测试、ESLint、Web 与 Electron 构建通过。
